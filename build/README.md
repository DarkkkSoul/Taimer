# App Icons

Place your app icons in this folder:

## Required Files:
- `icon.ico` - Windows icon (256x256 pixels or higher, .ico format)
- `icon.icns` - macOS icon (512x512 pixels or higher, .icns format)  
- `icon.png` - Linux icon (512x512 pixels, .png format)

## Icon Guidelines:
- Use high resolution (512x512 or 1024x1024)
- Simple, recognizable design
- Works well at small sizes
- Follows platform design guidelines

## Creating Icons:
1. Design your icon as a 1024x1024 PNG
2. Use online converters or tools like:
   - png2ico.com (for .ico files)
   - cloudconvert.com (for .icns files)
   - Or use Electron's icon generation tools

## Temporary Solution:
If you don't have custom icons yet, electron-builder will use default icons, but it's recommended to add your own for a professional look.
